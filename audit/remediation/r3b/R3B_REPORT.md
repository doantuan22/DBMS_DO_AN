# R3B — PASS

Đã áp dụng lên **CinemaBookingDB** ngày 2026-10-04. Backup COPY_ONLY/CHECKSUM + RESTORE VERIFYONLY PASS; migration atomic PASS; fingerprint dữ liệu cả 27 bảng, schema bảng và execution grants giữ nguyên. Hai DB kiểm chứng R3B đã xóa trước khi áp dụng DB chính thức. Không còn CinemaBooking trial DB.

1. **Root causes đã sửa:** Customer thiếu functional guards; SP Manager thiếu exact permission; Support dùng OR hoặc XULY đơn lẻ; DB implicit Admin bypass/NULL actor; frontend dùng quyền đại diện để khóa cả area và tải API ngoài grant. Mỗi lớp dùng active account → actor role → current permission (AND) → owner/current scope.
2. **Permission Matrix:** [CSV](PERMISSION_MATRIX.csv), [Markdown](PERMISSION_MATRIX.md), [JSON/source parity](evidence/endpoint-inventory.json): 118 endpoints, 104 protected, 14 public. XEM_PHIM giữ trong catalog và **NOT ENFORCED** trên public catalog. Promotion preview có public auxiliary reads và một SP validate protected; payment có own-read helper và SP write protected.
3. **DB:** sửa 2 functions + 100 procedures (99 SP hiện có và 1 wrapper Admin genre mới). [Danh sách đầy đủ](evidence/migration-files.json), [migration](../../../database/13_migrations/r3b_authorization_contract.sql). fn_KiemTraQuyenNguoiDung tra VAITRO_QUYEN cho mọi actor; fn_KiemTraQuanLyRapScope chỉ active QUAN_LY_RAP + assignment hiện hành và giữ fn_HomNay của R1. SP Customer/Manager/Support/Admin kiểm eligibility và mọi quyền bắt buộc. Admin SP và alias phân công truyền ActorID rõ ràng; hủy suất không dùng NULL. Public genre SP giữ nguyên, Admin có wrapper riêng. Trigger CSKH/Admin và Customer provisioning vẫn phù hợp nên giữ nguyên.
4. **Backend:** thêm DAT_VE vào booking/promotion, THANH_TOAN vào payment create/result, DANH_GIA vào review, GUI_KHIEU_NAI vào complaint create. Own GET giữ role + ownership. requirePermission hỗ trợ AND; Support/Admin processing/status cần QL+XULY, order-reference cần QL+TRA. Admin service/controller truyền authenticated actor riêng với target ID, không dùng state mutable chung. SQL 50300 → 401, 50301/50302 → 403, private foreign → 404; 409 dành cho business. Authenticate tiếp tục tải current user/permissions mỗi request; JWT chỉ sub/iat/exp. **Không thêm raw SQL vào Backend.**
5. **Frontend:** Customer/Manager/Admin area theo actor role; Support read theo QL. Menu lọc role, tab/action lọc exact permission. Customer history không bị write grant khóa. Manager chỉ load section được cấp, lỗi từng section không làm mất section khác; QL_GHE-only có thể nhập room ID xem/tạo ghế, QL_SUAT_CHIEU-only nhập room ID tạo suất. Admin chọn tab hợp lệ đầu tiên; QL_QUYEN-only có form gán quyền không đòi QL_VAITRO. Support detail không phụ thuộc order-reference, controls theo AND. 403 refresh current user, cập nhật UI và assignment bootstrap; không retry mutation.
6. **Admin bypass trước/sau:** trước function cấp Admin mọi quyền kể cả unknown, scope helper auto-pass và cancel wrapper truyền NULL; sau grant hiện tại bắt buộc, unknown=0, Admin không tự có Manager scope, cancel đi qua ADMIN + QL_SUAT_CHIEU với explicit actor. Admin global authorization là đường riêng theo P7, không dùng Manager-scope helper như global checker.
7. **Revocation:** [270 HTTP requests / 134 direct DB checks](evidence/probes.json) PASS. Token cũ sau revoke Customer write, Manager permission/assignment, Support combination, Admin grant đều DENY; khóa tài khoản → 401, đổi role → 403. Own order/complaint reads vẫn PASS khi gỡ toàn bộ write grants; foreign order/complaint/payment HTTP và payment SP giữ safe 404. JWT claims không chứa role/permissions/scope.
8. **Partial grants:** [26 kiểm tra trên React thật trong Chrome](evidence/partial-grants-browser.json) PASS: Manager seat/showtime/report-only; Admin report/user/grant-only; Support QL, QL+XULY, QL+TRA; Customer actions và lịch sử; menu không mở foreign role; permission/scope refresh sau 403 không retry thao tác. Unit test còn kiểm chứng một section lỗi vẫn giữ section khác.
9. **Parity:** source matrix đối chiếu từng route protected với actor/permission SP PASS; execution stubs kiểm tra 112 service methods, 120 captured procedure calls/types PASS; runtime DB/API denial/positive paths PASS. Frontend dùng cùng exact mapping và role eligibility; server vẫn là authorization boundary.
10. **Regression:** [16/16 checks](evidence/checks.json) PASS; Backend **102/102**, Frontend **35/35**. R1 fixed clock, timezone UTC/Vietnam/Los Angeles, browser create/edit PASS. R2 hold/payment/expiry/cancel/compensation/concurrent cancellation/retry/payment history/rollback PASS; booking concurrency và HTTP stress PASS. `npm.cmd run db:reset` trên fixture PASS; source parity **159/159** và DB verify PASS; frontend build/lint PASS. [Migration từ 158 module trước R3B trên fixture có lịch sử](evidence/migration-fixture.json) bảo toàn mọi bảng PASS; [idempotency](evidence/migration-idempotency.json) PASS. [Deployment main](evidence/main-deployment.json) và [verify/main final](evidence/main-final.json) PASS. [Main HTTP smoke](evidence/main-http-smoke.json): 31 requests PASS, 2 future-show detail/seats skips vì dữ liệu chính thức chưa có suất tương lai phù hợp; các ca này PASS trên fixture. Build vẫn có thông báo chunk >500 KB; lint không warning/error.
11. **Database:** vẫn **27 bảng**, 6 views, 21 functions, 7 triggers, **125 SP**, 63 indexes, 161 constraints; tổng **159 SQL modules**. Không thêm permission, role hay bảng RBAC. Baseline/manifest/verify đã cập nhật từ source. [Sau deploy và smoke](evidence/main-final.json) mọi dữ liệu/schema/grant còn nguyên; chỉ CinemaBookingDB còn trong nhóm database của ứng dụng.
12. **BUG-019:** **RESOLVED** — functional authorization được enforce ở route và SP; old JWT không giữ quyền đã thu hồi.
13. **BUG-020:** **RESOLVED** — bỏ coarse area gates, menu theo role, section/action theo quyền, partial grants hoạt động, 403 refresh UX.
14. **CONFLICT-005:** **RESOLVED** theo 8 policy đã chốt: role giữ actor eligibility; own reads không yêu cầu write permission; public catalog không enforce XEM_PHIM; QL/XULY/TRA dùng AND; Admin cần grant hiện tại; Manager scope riêng. Không phát sinh policy mâu thuẫn cần dừng.
15. **R3B: PASS.** Source, DB chính thức và bằng chứng kiểm chứng đã cập nhật; DB thử nghiệm đã xóa. Backup recovery location lưu tại `database/_audit/R3B-recovery-location.local.json` (local artifact, không đưa credentials vào evidence).
