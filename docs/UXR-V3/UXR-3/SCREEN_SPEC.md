# Screen and component contracts — 3B/C/D

Admin Seats and Manager Seats: header → current cinema/room named selectors → configuration/showtime mode and actual showtime selector when permission exists → search/row/type applied filters → dominant SeatLayout + SeatInspector. Configuration map is default; explicit list accessible fallback. Layout accepts normalized seats, selected ID, applied matches, mode and selection event; no fetching, permission, SQL or booking writes. Rows remain in numeric seat order while filters mute nonmatches; scroll and bounded zoom preserve readable controls. Missing row/number or duplicate position forces list fallback. No stage orientation, invented gaps, aisle or pair geometry. Inspector shows real identity labels/type/status, neutral history guard text, optional edit/delete actions; occupancy is read-only.

Manager Rooms: persistent assigned cinema selector → filters → curated ResourceTable → drawer create/edit. Seat action links paired real cinema/room context. Store draft and screen state persist across internal Manager routes; cinema epoch change resets them through existing store. Writes acquire existing store tokens; disposed screens ignore responses. Pending prevents context/navigation writes; Cancel/Confirm dirty guards apply to room changes/editor close; ManagerLayout retains multi-cinema guard for hidden drafts.

Admin Cinema: list-first filters/search → table with optional complete-data room count → selected detail panel with links to Rooms, Images and existing Showtimes → create/edit drawer. Cinema deletion confirmation states dependent-data rejection and Tạm đóng alternative; no cascade. Gallery keeps CinemaImageManager entry point: mandatory named cinema → thumbnail grid/status/cover/order → preview or create/edit drawer. Numeric order is the existing update API; no upload service. Failed image render uses neutral asset fallback independent of API status.

State owner: feature controller owns cinema/room/resource generations, exact DTO adapters, complete read data, selected resource, editor baseline/dirty, confirmations, synchronous write lock and disposal. Manager store owns assignment/cinema/epoch/global pending/hidden drafts. Query contains only cinema/room/showtime/filter/page IDs and nonsensitive names; never form drafts. Validate deep-link pairs against actual scoped lookup before read/write. 403/404/409 errors retain appropriate draft/data and never become empty. Successful mutations refresh original owner only after authoritative result.

Use UXR-2A PageHeader/FilterBar/ResourceSelect/ResourceTable/Dialog/ConfirmDialog/FormField/Input/Select/Button/StatusBadge/AsyncState and existing tokens. ≥1280px map+inspector two columns, mobile inspector below map; gallery cards and filters wrap at 390/768/1280/1440/1920. Keyboard native seat buttons, aria-pressed, horizontal scroll region, native dialog trap/restore and focus name field; browser acceptance must verify these expectations. No large dependencies, no redesign 3A or booking/showtime/pricing.
